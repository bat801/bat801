**Status:** Working prototype (Android) · Registered software patent (Rospatent)

Desktop application for automated object detection and counting using YOLOv8.
**Stack:** C# · WPF · Python · YOLOv8 · OpenCV
**Status:** Packaged as a single `.exe` installer

**Status:** MVP · Grantee of "Student Startup" (1M RUB) · Founded BeeX
